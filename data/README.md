- Download endpoint: [Kaggle ZIP download](https://www.kaggle.com/api/v1/datasets/download/ninzaami/loan-predication)
- Downloaded: 16 October 2026
- Kaggle license label: **CC0: Public Domain**
- Original archive filename: `train_u6lujuX_CVtuZ9i (1).csv`
- Included filename: `loan_data.csv`

The included CSV preserves the downloaded file's bytes. Only the filename was simplified. It contains 614 data rows and 13 columns, including the target `Loan_Status`. The notebook renames the columns in memory to camelCase. Missing values are original to the file; none were artificially added.

The Kaggle description says 615 rows. The CSV has one header row and 614 data rows. All reported results use the actual 614 data rows.
